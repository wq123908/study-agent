| 补充输入后继续 | 等待和恢复关联同一运行，已完成步骤按约定复用。 |
| 审批后模拟写入 | 权限一致，批准和拒绝都可审计，重复请求不会形成多次可见写入。 |
| 外部异步结果 | 等待外部信号后按标识恢复，支持状态查询、截止和取消。 |
| 第二个 Agent 与替换组件 | 两个 Agent 共用执行内核，模型、工具、存储和评测器能按契约替换。 |
